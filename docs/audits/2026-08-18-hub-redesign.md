# ハブを「カード＋一言・1画面」に変更（2026-08-18）

> `docs/ux-backlog.md` から 2026-09-25 に移した監査ログ（内容は書き換えていない）。判断の現行版は `docs/ux-backlog.md` の「やらないと判断したもの」「検討して現状維持と判断した事項」を見る。

## 2026-08-18 ハブを「カード＋一言・1画面」に変更（利用者「16本になって探すのはめんどくさい」）

**実測**: 変更前は 1280x900 で `scrollHeight` 2,093px ＝ **縦2.3画面**。カード1枚が
「名前＋長い説明＋いつ使う」の3要素で、16本並ぶと一覧の用をなしていなかった。

**3回作り直している。経緯を残す（同じ往復をしないため）**:
1. 名前だけのチップ（丸い小さなピル）で1画面に収めた → 利用者「**ちょっと使いにくすぎる。
   カードっぽく大きくして欲しい**」「**説明文もないとわかりにくい**」
2. アイコン＋名前＋一言のカードにし、カテゴリ名を行の左に置いた
   → 利用者「**まだちょっと使いにくいし見にくい。web 調べて参考にしても良い**」
3. → **現行 Web の実装調査**（GitHub Marketplace / Raycast / Stripe / Linear / Vercel / Notion の
   配信 CSS と構造）を経て**カテゴリ分割をやめ、1枚の 4×4 グリッド**に。カテゴリは絞り込みチップへ

**調査で分かった「見にくい」の正体（推測ではなく計算・実測）**:
- **升目の6割が空だった**。カテゴリごとに別グリッドにすると、5列の枠に1〜6本を流すことになり、
  7カテゴリ中4つが1〜2本しかないため**8行×5列=40枠に16枚（充填率40%）**。
  右側に穴が並ぶのが「見にくい」の主因で、カードの造形をいくら磨いても消えない
- **16 = 4×4** なので列数を 4→2→1 に固定すると**どの幅でも余りが出ない**。
  `auto-fit` は使わない（本数が少ない行でカードが全幅に伸びる）
- ダークモードで一言（`--muted` on `--panel`）が **4.06:1 で WCAG AA 不合格**だった
- ホバーで名前を accent 色にしていたため、**コントラストが 12.5:1 → 4.0:1 に落ちていた**
  （GitHub は文字色を変えず面色だけ変える）
- ダークでカードの枠が面との差 **1.36:1** しかなく、影も無いので輪郭が消えていた
- 一言 11.5px は日本語には小さすぎ（実例はいずれも 13〜14px）。かつテキスト列 152px に対し
  最長の一言が 149.5px と限界で、1枚でも折り返すと**同じ行の5枚すべてが高くなる**構造だった

**現行の作法（実例に準拠）**: 影で立てず枠と面で見せる／ホバーは面色だけ（動かさない・文字色を変えない）
／アイコンは角丸タイル（42px に 23px グリフ・内側1pxリング）に載せて**絵文字ごとの視覚的な重さの差を吸収**
／タイル色はカテゴリ色だが、意味はチップと `title` が担う（色だけに意味を持たせない）

- **決定**: カード（アイコン＋名前＋`short` 一言）を**1枚のグリッド**に。全16本が1画面に収まる
  （HUB-18 が 900px 以内をピン）。**列数は3**（利用者の指定 — 4列より1枚が大きい方が良い。
  16本なので最終行は1枚になるが、左端に付けて中央寄せしない）。
  カード 382×84px・アイコンタイル46px・1280x900 で content 893px（余裕7px）。
  **寸法や本数を変えたら必ず測り直す**（余裕が小さいので他の環境で溢れうる）。**長い説明（desc）と用途（when）は画面から消し、
  `title` 属性と検索にだけ残す**（HUB-17）
- **カテゴリは絞り込みチップ**（件数つき＝目次も兼ねる。押すと絞る・もう一度押すと解除・検索と合成 HUB-21）。
  並びは CATEGORY_ORDER 順のままなので、同カテゴリはタイル色の帯として隣り合って見える
- **`short`（カードの一言）と `icon` を TOOLS に追加**。icon は各ツールの favicon が基本だが、
  U+FE0F が要るもの（board/doc2xl/devpad）と重複するもの（excel2md と gantt が同じ）は差し替えた。
  **HUB-17 がアイコンの重複を検出する**（目印にならないため）
- **DOM の契約が変わった**: リンクのテキストは「アイコン＋名前＋一言」なので、
  **表示名で要素を選ぶときは `.tool-name` を使う**（全16ハーネスのハブ導線を追随させた）
- **desc は短くしない** — 表示から外れたので、機能名・別名を盛り込むほど検索で辿り着ける
  （HUB-11 が devpad の4タブ名で引けることをピン）。「画面を簡素にする」ことと
  「検索を賢くする」ことが両立する形にした
- **最近使った**（`tools:hub`・上限5・ハブ経由で開いたときだけ記録）を先頭に追加（HUB-19）
- **検索へ自動フォーカス＋Enter で先頭を開く**（HUB-20）。**IME ガード必須**
  （変換確定の Enter で遷移させない — taskboard TB-I の教訓を横展開）
- 見送り: カテゴリの折り畳み・お気に入りのピン留め・使用回数順。
  トリガー: 最近使った5件で足りないと感じたとき（回数順は「たまに使う道具」が沈むので慎重に）
