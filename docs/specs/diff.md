# diff 仕様書兼テストケース

## 概要

2つのテキストの差分を行単位＋変更行内の文字単位で表示するツール。`web/diff.html`、カテゴリ: 変換。LCS 系アルゴリズム（Myers）の自前実装（ライブラリ不可）。数千行で固まらないことが必須要件。

## 要件対応表

| ユーザー要件 | spec 節 |
|---|---|
| 2ペイン入力→差分表示 | 画面構成 |
| 行単位差分＋変更行内の文字単位ハイライト | アルゴリズム仕様 |
| LCSベースの自前実装 | アルゴリズム仕様 1 |
| 数千行で固まらない／行単位のみフォールバック閾値 | 性能仕様 |
| 前後空白を無視オプション | オプション仕様 |
| 全角半角を同一視オプション | オプション仕様 |
| 差分サマリ（追加N/削除N/変更N行） | サマリ仕様 |

## 画面構成

- `<main>` 直下: `.tool-header`（「← ツール一覧」リンク＋「設定は自動保存されます」注記） — 見出し2行（`header.app-head` の中。説明は h1 の title・操作は2行目 `.app-controls` — 2026-10-05 段5・HUB-28）
- 上段2ペイン: 左=旧テキスト、右=新テキスト（textarea）
- 旧テキストペインタイトル横: 「サンプルを入れる」ボタン（**両ペインが空のときのみ表示**。
  文字違い・全半角違い・行頭空白違いを1箇所ずつ仕込んだ2テキストを同時投入）
- ツールバー右: 「diffをコピー」ボタン（**Cmd/Ctrl+Enter でも実行**）。画面と同じ順序の
  マーカー付きテキスト（`- `/`+ `/2スペース＝一致行、折り畳みは展開して全行）をコピー。
  clipboard API → 失敗時は一時 textarea 選択方式。空のときは「コピーする内容がありません」
- 下段: 差分表示（unified 1カラム →DIFF-Q1）＋サマリ行＋オプションチェック
- サマリ: 差分ゼロかつ入力ありのときは「差分なし — 」を前置（例: `差分なし — 追加 0行 / 削除 0行 / 変更 0行`）
- 入力は 200ms デバウンスで再計算

## アルゴリズム仕様

1. **行単位**: 行分割 → オプション適用した比較キー生成（前後空白無視=trim、全半角同一視=`normalize('NFKC')`。表示は常に原文）→ キーを整数にインターン → 共通プレフィックス/サフィックスをトリム → 中央部を **Myers O(ND) greedy** で差分化。**D_MAX=1000**、V配列とトレースは事前確保した Int32Array を再利用（毎回の大量アロケーション禁止）
2. **D_MAX 超過時**: 中央部を「全行削除＋全行追加」の一括置換ハンクに退避し警告バナー「差分が大きすぎるため中間部を一括の変更として表示しています」。`fallback: true` を返す
3. **文字単位**: 置換ハンク内で i 番目の削除行と i 番目の追加行をペアリング（余剰は純追加/削除）。各ペアに同じ Myers をコードポイント配列で適用。**適用条件**: 行長 ≤400 / 文字編集距離 ≤200 / 変更行ペア累計 ≤200 / 総行数 ≤10,000。**共通文字率 40% 未満のペアは文字ハイライトせず行全体を変更表示**（無関係な行同士のノイズ差分防止）。条件外は行単位表示のみ
4. **全半角同一視 ON 時の注意**: キーが等しい行は「変更なし」になる。変更行内の文字差分は原文で行うため、幅違いはそのままハイライトされる（仕様として明記）

## 性能仕様

- **入力ガード（超過時は比較せず理由を表示）**: 合計 5,000,000 文字超 または 片側 50,000 行超 → 「入力が上限（合計500万文字・片側5万行）を超えたため比較を中止しました」
- 3,000行×編集30箇所規模: 差分計算の中央値 500ms 未満（検証で5回計測）
- 全行相違の5,000行ペア: フォールバック発動し応答を維持
- 描画: 一致行の連続 20 行超は「… N行 一致 …」に折り畳み（クリックで展開）。再計算時は折り畳み状態はリセット・scrollTop は復元（仕様として明記）
- 行の DOM は DocumentFragment でまとめて構築、textContent のみ使用

## オプション仕様

| オプション | 既定値 |
|---|---|
| 前後空白を無視 | OFF |
| 全角半角を同一視 | OFF |

永続化する（DIFF-Q2 で決定。`tools:diff`）。

## サマリ仕様

置換ハンク内: `min(削除数, 追加数)` = 変更行、余剰 = 追加または削除。純追加/削除ハンクはそのまま加算。表示例: `追加 3行 / 削除 1行 / 変更 5行`（→DIFF-Q3）。

## エラー・警告仕様

- 空入力（片側/両側）でも落ちない（全追加/全削除/差分なし表示）
- フォールバック時は必ず警告バナー（黙って劣化しない）

## 保存仕様

キー `tools:diff`、payload `{ignoreWs: bool, unifyWidth: bool}`（DIFF-Q2 で決定）。入力テキストは保存しない。

## テストケース

`window.diff.diffLines(a, b, opts)` → `{hunks, summary, fallback}` で照合。

| ID | 前提 | 入力 a / b | 期待 |
|---|---|---|---|
| DIFF-01 | 既定 | `'a\nb\nc'` / `'a\nx\nc'` | summary `{added:0, deleted:0, changed:1}`、fallback:false |
| DIFF-02 | 既定 | `'a\nb'` / `'a\nb\nc'` | summary `{added:1, deleted:0, changed:0}` |
| DIFF-03 | ignoreWs:true | `'a \n  b'` / `'a\nb'` | 差分なし（summary 全0） |
| DIFF-04 | unifyWidth:true | `'ＡＢＣ'` / `'ABC'` | 差分なし（summary 全0） |
| DIFF-05 | 既定 | `'こんにちは世界'` / `'こんばんは世界'` | changed:1。文字差分: 旧 `'にち'`（[2,4)）→ 新 `'ばん'`（[2,4)） |
| DIFF-06 | 既定 | `''` / `'a\nb'` | summary `{added:2, deleted:0, changed:0}` |
| DIFF-07 | 既定 | 3,000行で約30箇所編集した生成ペア | fallback:false、5回計測の中央値 <500ms |
| DIFF-08 | 既定 | 全行相違の5,000行ペア | fallback:true、応答あり、警告バナー |

UI 手順ケース:
- **DIFF-09**: DIFF-01 を UI 入力 → 差分ペインに変更行表示・サマリ一致
- **DIFF-10**: 1,000行ペアを UI 入力 → 描画成功・折り畳み表示・操作可能
- **DIFF-11（性能ガード）**: 片側 50,001 行を入力 → 比較せず中止警告バナー・差分ペイン空
