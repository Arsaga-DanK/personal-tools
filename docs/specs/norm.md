# norm 仕様書兼テストケース

## 概要

日本語テキストの表記ゆれを正規化するツール。`web/norm.html`、カテゴリ: 変換。変換オプションは個別 ON/OFF でき、設定は ToolStorage で記憶。出力ペインで変更文字をハイライトし、適用した変換の種類と件数をサマリ表示する。

## 要件対応表

| ユーザー要件 | spec 節 |
|---|---|
| 変換オプション個別ON/OFF、設定はstorage.jsで記憶 | オプション仕様 / 保存仕様 |
| 全角英数→半角 / 半角カナ→全角 | 変換仕様 T2, T3 |
| ハイフン・マイナス・長音類の統一（統一先を選択可） | 変換仕様 T4 |
| 波ダッシュ統一 | 変換仕様 T5 |
| 連続空白の圧縮 | 変換仕様 T6 |
| NFKC一括 | 変換仕様 T1 |
| 変更文字のハイライト（前後対比が見える） | ハイライト仕様 |
| 適用変換の種類と件数のサマリ | サマリ仕様 |

## 画面構成

- `<main>` 直下: `.tool-header`（「← ツール一覧」リンク＋「設定は自動保存されます」注記）
- 2ペイン: 左=入力 textarea、右=出力（`white-space:pre-wrap` の mono `<div>`、変更箇所ハイライト付き）＋「結果をコピー」ボタン（コピーのフォールバックは**一時 textarea 選択方式** — 出力 div の選択はルビ注記の `<rt>` が混入するため使わない）
- オプション列（`.opts`）: 各変換のチェックボックス＋ハイフン統一先セレクト＋波ダッシュ方向セレクト。
  **各オプションに変換例つき title（tooltip）**を付け、意図的仕様（空白圧縮は半角のみ /
  全角記号は NFKC の領分 / NFKC は他変換優先）をその場で説明する（UX監査 NM-1/2/3）
- 入力ペインタイトル横: 「サンプルを入れる」ボタン（**入力が空のときのみ表示**。既定ONの全変換が
  1回以上発火し、NFKC の領分の文字はあえて残る例文を投入）
- コピーは **Cmd/Ctrl+Enter でも実行**（コピーボタンの title に表記）
- サマリ行: 「全角英数→半角: 6件 / 連続空白圧縮: 2件」形式
- 設定エクスポート/インポートボタン（ToolStorage）
- 入力は 150ms デバウンスでリアルタイム変換

## 変換仕様

**トークンパイプライン**: 入力をコードポイント単位のトークン `{orig, cur, changedBy: []}` に分解し、各変換がトークン列を書き換える。N:1 マージ（`orig` 連結）と 1:N 展開（`cur` が複数文字）に対応。**ハイライトと件数はこの構造から導出されるため常に正確**。

**前処理（無条件）**: 結合記号 U+FF9E/U+FF9F（半角濁点・半濁点）、U+3099/U+309A（結合用濁点・半濁点）および一般の結合文字（Mn/Mc）を直前トークンへマージ。単独の U+309B/U+309C は U+3099/U+309A 相当として直前トークンに付け、**NFC 合成する**（例: `ウ゛`→`ヴ`。orig≠cur となりハイライトで可視化・tooltip は「前処理（濁点合成）」表示。サマリの件数には含めない）。U+309B/U+309C は **NFKC の除外集合に常時含める**（raw NFKC の「スペース＋結合文字」展開は採用しない — 空白圧縮との干渉と宙に浮く結合文字を防ぐため。仕様として明記）。

適用順と各変換（IDは実装・サマリ・テストで共通）:

| ID | 変換 | 既定 | 内容 |
|---|---|---|---|
| T1 nfkc | NFKC一括 | OFF（→NORM-Q1） | トークン単位で `normalize('NFKC')`。ただし**有効な他変換が所有する文字はスキップ**（除外集合方式）: T4 有効時はハイフン族（**長音は「長音ーも対象」設定時のみ** — OFF時に除外すると ｰ の正規化がどの変換にも属さず死蔵するため）、T5 有効時は 〜/～、U+309B/U+309C は常時。オプションの死蔵（例: NFKC が先に ～→~ にして波ダッシュ統一が無効化）を防ぐ |
| T2 alnum | 英数字の全半角統一 | ON・統一先=半角 | **統一先セレクト（2026-08-13 で双方向化）**: 半角（既定。U+FF10-FF19 / U+FF21-FF3A / U+FF41-FF5A を −0xFEE0）／全角（A-Za-z0-9 を ＋0xFEE0）。全角記号（！？（）等）を含めるかは →NORM-Q2。**サマリ・tooltip のラベルは方向に追随**（半角=「全角英数→半角」／全角=「半角英数→全角」— 既定方向では従来の文言と同一） |
| T3 kana | カナの全半角統一 | ON・統一先=全角 | **統一先セレクト（同上）**: 全角（既定。半角カナだけのトークンに `normalize('NFKC')` を局所適用 — 2026-08-13 訂正: 旧記述「明示マップ」は実装と乖離していた）／半角（**NFKC の逆引きマップを実行時生成** — U+FF61-FF9F の各文字と ﾞﾟ 合成の NFKC 結果を反転。手書き表を持たない）。濁点付きは ｶ+ﾞ→ガ／ガ→ｶﾞ とも1トークン・件数1。半角カナ領域の句読点・括弧（｡｢｣･､）も両方向の対象（対称性）。ラベルは方向に追随（「半角カナ→全角」／「全角カナ→半角」） |
| T4 hyphen | ハイフン・マイナス統一 | ON | 対象: ‐(U+2010) ‑(U+2011) ‒(U+2012) –(U+2013) —(U+2014) ―(U+2015) −(U+2212) ﹣ －(U+FF0D)。統一先セレクト: `-`(U+002D) / `−`(U+2212) / `ー`(U+30FC) / `–`(U+2013)、既定 `-`。**長音 ー(U+30FC)/ｰ(U+FF70) は既定で対象外**（カタカナ語破壊防止）、含めるチェックを別途用意 |
| T5 wave | 波ダッシュ統一 | ON | 〜(U+301C) ⇄ ～(U+FF5E)。方向セレクト、既定方向 →NORM-Q3 |
| T6 space | 連続空白の圧縮 | ON | 半角スペース2連以上→1個。全角スペース・タブを対象に含めるかは →NORM-Q4 |

## オプション仕様

上表の ON/OFF・統一先・方向すべてを `tools:norm` に永続化（変更即保存）。復元失敗時は既定値。

## ハイライト仕様

- 変更トークン（`orig !== cur`）を `<span class="chg" title="変更前: <orig> [変換名]">` で描画。未変更部分はテキストノード
- 隣接する同種（同一 changedBy）の変更トークンは1つの span に結合、未変更の連続もまとめる（DOM 節約）
- **上限**: 変更 span 1万個超 または入力 64KB 超はハイライトを省略しプレーン出力＋バナー「入力が大きいためハイライトを省略しました」（サマリは表示）
- 変更前の表示方式 →NORM-Q5
- 出力は textContent/createElement のみで構築（innerHTML 不使用）

## サマリ仕様

変換ごとに「触れたトークン数」を表示（例: `全角英数→半角: 6件`）。0件の変換は表示しない。1トークンが複数変換で変更された場合は各変換のカウントに1ずつ計上。

## 要注意文字の検出（2026-08-13）

Excel 納品・レガシー DB 投入の前に「環境で化けやすい文字」を可視化する。**検出のみで変換はしない**。
判定は**変換後の出力**（`t.cur`）に対して行う — 納品するテキストの検査だから
（例: NFKC ON なら ① は 1 に変換され、要注意から消える）。
トグル「要注意文字を検出」（`attention`・既定 ON）。

クラス（この列挙が正本。**完全な CP932 収録判定はしない** — 変換表が必要。
必要になったら tool-backlog の enc 候補を再検討する）:

| クラス | ラベル | 範囲 |
|---|---|---|
| 囲み・組文字 | `囲み・組文字（機種依存）` | U+2460-24FF（丸数字等）/ U+2160-217F（ローマ数字）/ U+3220-32FF / U+3300-33FF（㈱・㌔・㎡ 等）。CP932 には NEC/IBM 拡張で載るが JIS X 0208 外で環境により化ける |
| 異体字 | `異体字（機種依存）` | 代表6字を列挙: 﨑(U+FA11) 髙(U+9AD9) 德(U+5FB7) 濵(U+6FF5) 栁(U+6801) 瀨(U+7028)。増減はテスト更新とセット |
| BMP外 | `BMP外（絵文字等 — CP932に無い）` | U+10000 以上（サロゲートペア） |
| 不可視 | `不可視文字` | NBSP(U+00A0)・ゼロ幅(U+200B-200F)・行/段落区切り(U+2028/2029)・BOM(U+FEFF) |

- `normalize` の戻り値に `attention: { total, byClass: {ラベル: 件数} }` を追加
  （既存キー text/tokens/counts は不変。件数はトークン単位・最初に一致したクラス1つに計上）
- ハイライト: 該当トークンを `.ng` クラス（赤系）で描画し、title に `要注意: <ラベル>`。
  変換と重なったトークンは `.chg.ng`（title に両方）
- サマリ: 末尾に ` ／ 要注意文字: N件（ラベル: n …）` を追記（0件なら出さない。
  変換が0件でも要注意があれば「変更はありません ／ 要注意文字: …」）
- 保存: options に `attention`（boolean）を追加

## エラー・警告仕様

- どの入力でも落ちない。**空入力は出力空・サマリなし**（`summary` は空文字。0件時の
  「変更はありません」も出さない）。**「変更はありません」は入力があるときだけ**出す
  — 何も変わらなかったというフィードバックは入力があって初めて意味を持つため
  （diff の「差分ゼロかつ入力ありのとき」と同じ扱い。2026-08-05 に実装をこの規定に合わせた）
- **性能ガード**: 入力が 1,000,000 文字を超えたら normalize 自体を実行せず警告「入力が上限（100万文字）を超えたため処理を中止しました」（ハイライト省略の 64KB/1万span 閾値とは別。一部のみ処理はしない）
- ToolStorage 不可時は `mountWarning()` バナー＋設定はセッション内のみ有効

## 保存仕様

キー `tools:norm`、payload `{options: {nfkc, alnum, alnumTarget, kana, kanaTarget, hyphen, hyphenTarget, hyphenIncludeChoon, wave, waveTarget, space, attention}}`。
`alnumTarget` は `'half'|'full'`（既定 half）、`kanaTarget` は `'full'|'half'`（既定 full）。
**旧 payload（Target キーなし）は既定方向で復元**（後方互換）。
エクスポート/インポートは ToolStorage 標準（インポートは全置換 →devpad spec DEV-Q4）。

UI 手順ケース:
- **NORM-10**: NORM-01 入力時、出力ペインの `.chg` 要素数が期待変更箇所数と一致（隣接結合後の数を spec 化: `'ＡＢＣ１２３'` 全 6 文字が連続変更 → 結合により 1 span）
- **NORM-11**: オプション変更 → `tools:norm` 更新 → リロード → 復元
- **NORM-12**: エクスポート → インポート → 設定一致
- **NORM-15（性能ガード）**: 1,000,001 文字を入力 → 出力空＋中止警告バナー
- **NORM-16（コピー時の確定）**: 入力直後（150ms のデバウンス確定前）にコピー →
  **最新の入力に対応する出力**がコピーされる（デバウンス中の古い `lastResult` を渡さない。
  excel2md / diff と同じ「コピー時に確定」の規約）
- **NORM-22（要注意ハイライト）**: `'①'` 入力（全変換OFF）→ 出力ペインに `.ng` span が1つ・
  title が `要注意: 囲み・組文字（機種依存）`・サマリに `要注意文字: 1件` を含む。
  コピーされるテキストに影響しない

## 決定事項（要確認の承認結果・2026-08-03。9/10 はユーザー明示確認済み）

- **NORM-Q1**: NFKC の既定値 → **決定: OFF**（ユーザー明示。～→~、①→1 等が破壊的なため明示 ON で使う）
- **NORM-Q2**: 全角記号を T2 に含めるか → **決定: 含めない・英数字のみ対象**（ユーザー明示。記号は NFKC の領分）
- **NORM-Q3**: 波ダッシュの既定方向 → **決定: ～→〜**（U+301C へ。方向は選択可）
- **NORM-Q4**: 連続空白圧縮の対象 → **決定: 半角スペースのみ**（全角スペースは意図的な字下げが多い）
- **NORM-Q5**: 変更前の表示方式 → **決定: ハイライト＋hover tooltip 既定、「変更前を注記表示」トグルで `<ruby>` インライン表示**
