# mask 仕様書兼テストケース

## 概要

スクリーンショットのマスキングと注釈のツール。`web/mask.html`、表示名 `Mask`、カテゴリ: 画像（新設）。
画像を貼り付け（Ctrl+V）→ 機密部分をピクセル化/黒塗り → 矢印・枠・テキストで説明 → PNG で
コピー/保存。Teams・設計書に貼る前の1画面完結を狙う。

**ぼかし（ガウス）は提供しない** — 復元リスクが議論されており、機密用途の相場は
ピクセル化か黒塗り（2026-08-14 の外部調査。image-scrubber 等の OSS 実例に整合）。

## 入力

- **Ctrl+V 貼り付け**（`paste` の `clipboardData.items` から image blob — file:// で動く）
- ファイル選択・ドラッグ＆ドロップ
- 取り込みガード: 最大辺 6,000px 超は中止して理由表示（一部処理はしない）
- **保存しない**: 画像・操作履歴とも localStorage に入れない（機密画像を残さない。注記に明記）

## 操作モデル（元画像＋操作リスト。再描画は「元画像 → ops を順に適用」＝非破壊）

| op | 形 | 描画 |
|---|---|---|
| mosaic | `{type:'mosaic', x,y,w,h, size}` | 領域をピクセル化（縮小 → `imageSmoothingEnabled:false` で拡大。size=セル px・既定16） |
| fill | `{type:'fill', x,y,w,h, color?}` | 塗りつぶし。color 省略 = 黒（黒塗り）・`#ffffff` = 白塗り（v5。パレット対象外 — MK-Q15） |
| rect | `{type:'rect', x,y,w,h, color?, width?}` | 枠（塗りなし）。color 省略 = 赤・width 省略 = 3（細2/標準3/太5 — v5） |
| arrow | `{type:'arrow', x1,y1,x2,y2, color?, width?}` | 矢印（三角の頭は線幅に比例 L=4×width）。color 省略 = 赤・width 省略 = 3 |
| badge | `{type:'badge', x,y, n, color?}` | 番号スタンプ（半径14の円＋白抜き数字。v5）。移動・色変更可・リサイズなし |
| text | `{type:'text', x,y, text, color?}` | テキスト（20px・太字）。color 省略時は赤。**text は `\n` 可**（v3）— op.y は1行目の baseline・行高 26px。外接箱 = `{x-2, y-20, 最長行幅+4, 26×行数}`（1行のとき v2 の式と同一） |

- **Undo = スナップショット履歴**（v2 で一般化）: 追加・移動・削除・クリアの各操作前の状態へ
  1手ずつ戻る（追加→undo で図形が消える挙動 = MK-06 は不変）。クリア = ops を空に（画像は残す）
- マウス: ドラッグで矩形系（mosaic/fill/rect）と arrow。text は**クリックでその場に入力**（v3 — 下記）

## 選択・編集（v2・2026-08-14 利用者要望「置いた図形の移動ができないのは終わってないか」）

- ツールに**「選択」**を追加（既定ツールは引き続き mosaic — MK-Q3 不変）
- クリックで図形を選択 → **ドラッグで移動**。何もない所をクリック / Esc で解除。
  ツールを切り替えたら解除（破線が描画の邪魔にならない）
- **Delete / Backspace で選択図形を削除**。テキスト入力欄など入力要素にフォーカスが
  あるときと IME 変換中は無効（文字消しで図形が消えない — coding-rules の入力ガード）
- 当たり判定は**最前面（後に置いた方）優先**。fill/mosaic/rect = 矩形内、
  arrow = 線分から 8px 以内、text = 描画文字列のバウンディングボックス（measureText）
- **選択中の破線枠はオーバーレイ（別キャンバス・pointer-events なし）に描く** —
  出力 PNG（コピー・保存はメインキャンバスから生成）に混入しない

## パワポ風の編集操作（v3・2026-08-15 利用者要望「PPT/Canva の操作感に。先に打ってクリック配置は聞いたことがない」）

### テキストのその場編集（ツールバーの事前入力欄 `#text-input` は廃止）

- テキストツールで**クリック → その位置に編集ボックス（textarea）**が開き直接入力（複数行可）
- 既存テキストは選択ツールで**ダブルクリック → 再編集**（編集中はそのテキストを描画から外し、選択枠も出さない）
- **確定 = 外側クリック（blur）／ Esc ／ Cmd(Ctrl)+Enter**。
  意味論は Excalidraw 準拠（textWysiwyg.tsx を 2026-08-15 に一次確認:
  Esc=submit・blur=submit・Cmd/Ctrl+Enter=submit・IME 中の keydown は無視・空は作らない/削除）
- **IME ガード**: 変換中（`isComposing` / `keyCode 229`）のキーは編集操作に使わない
- 空で確定: 新規は何も作らない。既存は**削除**（1手として Undo で戻せる）
- 確定時に**末尾の改行のみ**除去。確定後は**そのテキストを自動選択**
  （**キャンバス上のクリックで確定したときは、そのクリックの当たり判定が優先** —
  空白クリックなら PPT と同じく解除される。Esc・キャンバス外クリックの確定は自動選択）
- 編集ボックスは表示スケール追従（フォント = 20px×スケール・**下限 12px** —
  6000px 級を縮小表示中は WYSIWYG が崩れる。位置は正しいまま）
- **編集セッションの横断ルール**: コピー・保存・Undo・クリア・ツール切替・Cmd+Z の**前に強制確定**。
  **画像の取り込みが成功したときだけ破棄**（旧画像座標のテキストを新画像に確定させない。
  上限超過などで**中止されたときは編集を維持**する — 入力中の文言を無警告で失わない）

### リサイズハンドル

- 選択中の fill/mosaic/rect に**8ハンドル**（角4＋辺4）。arrow は**端点2つ**（p1/p2）。
  **text はハンドルなし**（移動＋再編集のみ。フォントサイズ変更は非搭載）
- ハンドルは**画面上で常に約8px**（表示スケール補正）。当たり判定は画面6px 相当・**角を優先**・
  ハンドル > 図形本体 > 背後の図形の順
- 画面上の幅か高さが **24px 未満の図形は辺ハンドルを間引き角のみ**（判定域が本体を覆って移動不能になるのを防ぐ）
- リサイズは**クランプ方式**（反転しない・最小 2px）。arrow は**長さ 2px 未満に潰さない**（拒否）。
  キャンバス外へのクランプはしない（v2 の移動と同じ）
- 1ドラッグ = 1手（Undo。最初に動いた時だけスナップショット — v2 の移動と同型）。
  **1度も適用されなかったドラッグ（矢印を 2px 未満に潰そうとした等）は履歴に何も残さない**
  （無変化の1手で Undo を1回無駄にしない）

### 描画後の自動選択とツール復帰

- 図形の描画確定後: **自動選択し、ツールを「選択」へ復帰**（PPT の標準挙動）。
  **テキストはエディタを開いた時点で復帰**する（Excalidraw と同一。確定時に復帰させると、
  同じクリックの途中でツールが変わり pointerdown の後半が別ツールとして解釈される —
  2026-08-15 コードレビュー指摘1）。確定後の自動選択は同じ
- 編集中に外側をクリック = 確定＋そのクリックは選択ツールの意味論（空白なら選択解除 — PPT と同じ）
- ツールバーの**「連続描画」チェック**（既定オフ）でオンの間は**ツール維持・自動選択なし**
  （Excalidraw のツールロックと同じ。連続モザイクの最頻動線 = MK-Q3 を守る）。設定は保存しない。
  **テキストではオンの間、確定と同じクリックで次の編集ボックスが開く**（連続配置）
- **プログラム的なツール復帰では選択を解除しない**（「利用者によるツール切替は解除」= v2 仕様と区別）

### 移動の微小閾値とキーボード

- ドラッグ移動は**画面 3px を超えてから**適用（ダブルクリック前の「幻の 1px 移動」が Undo 履歴を汚さない）
- **矢印キー**: 選択図形を 1px 移動（**Shift で 10px**）。**連続ナッジは1手**
  （区切りはタイマーではなく「選択変更・別操作・Undo」— テストが flaky にならない）
- **Cmd/Ctrl+Z = Undo**。**Shift 付きでは発火しない**（Redo と誤解した操作で逆走させない）
- キーボード操作は入力要素フォーカス中は無効（従来どおり）
- カーソルは**選択ツールのみ**「ハンドル = 方向別リサイズ / 図形上 = move / 他 = default」。
  描画ツールは crosshair を維持
- **粒度セレクトは選択中のモザイクにも適用**される（1手として Undo 可能）—
  書式コントロールは選択図形に効く（PPT と同じ。2026-08-15 UX ウォークスルー指摘）
- **編集ボックスの幅はクランプ後の実フォントで計算**する（下限 12px 適用時に
  位置スケールのままだと文字が見切れる — 同ウォークスルー指摘）。
  高さも1行ぶん（lib/ui.css の変換ツール用 `min-height:220px` を上書きする）
- ツールボタン（ラジオ・チェック）にフォーカスが残った状態でも、**図形が選択されていれば
  矢印キー / Delete は図形操作が優先**（ラジオのグループ移動に奪わせない。
  テキスト入力系の要素 = textarea / select / テキスト入力 input のみガード）

## 色と道具箱の視覚化（v4・2026-08-15 利用者要望「色変え・ツールが書いてるところが分かりにくい」）

### 色パレット

- 注釈系（**枠・矢印・テキスト**）に5色パレット: 赤 `#dd2222`（既定）・青 `#2563eb`・
  緑 `#16a34a`・オレンジ `#f59e0b`・黒 `#111111`。op に `color` を持つ（省略 = 赤 — 後方互換）
- **モザイク・黒塗りには効かない**。黒塗りは黒固定 — マスキングは「隠す」が目的で、
  色が選べると隠せていない事故を招く（MK-Q13）
- **選択中の図形（枠・矢印・テキスト）にも適用**される（粒度と同じ「書式は選択に効く」規則。
  1手として Undo 可能）。モザイク・黒塗りを選択中は何もしない（履歴も積まない）
- テキスト編集ボックスの文字色もパレットに追従（開いた時点の色）
- 自由色ピッカー（`input[type=color]`）は載せない — 選択肢過多とプラットフォーム差を避ける（MK-Q14）

### ツールバーの視覚化

- ツール群（選択〜テキスト）を**セグメント化**し、**アイコン＋ラベル＋押下状態**（accent 背景）で
  現在のツールをひと目で分かるようにする。ラジオ構造（`input[name="tool"]`）は不変 — テスト互換
- 書式（色・粒度）・実行（元に戻す・クリア）・出力（コピー・保存・開く）をグループ分け
- 各ツールに title（何ができるかの一言）

### フック追加

`countColor(x,y,w,h, [rLo,rHi, gLo,gHi, bLo,bHi]) → n`（範囲指定版の countRed — 色検証用）

## 拡充6点（v5・2026-08-15 利用者「全て採用します」＋「貼り付けた画像が左寄せ → 中央寄せに」）

### 表示

- **キャンバスは中央寄せ**（`#canvas-wrap` を fit-content＋auto マージン。狭幅では従来どおり全幅相当）

### 線の太さ（枠・矢印）

- 書式グループに「太さ」（細2 / 標準3 / 太5）。`op.width`（省略 = 3 — 後方互換）
- 矢印の頭は線幅に比例（L = 4×width。標準で従来の 12 と一致）
- **選択中の枠・矢印にも適用**（色・粒度と同じ「書式は選択に効く」規則。1手として Undo）

### 白塗り（マスクの白版 — 修正テープ）

- 独立ツール「白塗り」= `fill` の `color:'#ffffff'`。書類系スクショの隠蔽用
- **パレットはマスク系（モザイク・黒塗り・白塗り）に効かないまま**（MK-Q13 は維持。
  隠蔽色はツールで固定 — MK-Q15）

### 複製（Cmd/Ctrl+D）

- 選択図形を **+10,+10 にずらして複製し、複製側を選択**（1手として Undo）。
  何も選択していないときは何もしない（ブラウザ既定のブックマークも抑止しない）
- バッジの複製は**次の番号**を振る（同番号が2つ置かれるのは番号の意味に反する — MK-Q19）

### Shift 制約（PPT の筋肉記憶）

- **矩形系の描画**: Shift+ドラッグで正方形（辺 = max(|dx|,|dy|)、開始点アンカー）
- **矢印の描画**: Shift で角度を 45° 刻みにスナップ（長さは維持）
- **移動**: Shift で水平/垂直の軸ロック（開始点からの総移動量の大きい軸に固定）
- リサイズの等比制約は対象外（要望が出たら — MK-Q18）

### 番号スタンプ ①②③

- ツール「番号」: クリックで番号入りの円を置く（半径14・パレット色・白抜き数字）
- **採番 = 既存バッジの最大値 + 1**。削除しても振り直さない（置いた順の意味を保つ — MK-Q16）
- 移動・色変更・削除は他の注釈と同じ。リサイズ・再編集はなし

### 切り抜き

- ツール「切り抜き」: ドラッグで範囲指定 → **オーバーレイにプレビュー**（範囲外を暗く・破線）→
  バナーの**［切り抜く］ボタンで確定**（誤爆防止の確定式）
- 確定で: 元画像を範囲に差し替え・全 op の座標をシフト・**履歴はリセット（Undo 対象外）**
  — 画像の履歴を持つと機密画像の複製を保持することになり「保存しない」方針と矛盾（MK-Q17）
- キャンセル = Esc・ツール切替・範囲外の小さすぎるドラッグ（8px 未満）。
  プレビューはオーバーレイのみ（確定前にコピーしても PNG に混入しない）
- 最小サイズ 8×8・範囲は画像内にクランプ

## 出力

- **PNG コピー**: `canvas.toBlob` → `ClipboardItem({'image/png': Promise<Blob>})`
  （Safari はジェスチャ内で同期的に write するため **Promise を渡す形**が必須 — 調査済み）。
  失敗時は「PNG 保存を使ってください」の案内
- **PNG 保存**: `<a download>` ＋ dataURL

## 純関数・フック（UI と同一コードパス）

`window.mask = { setImage(dataUrl) → Promise, addOp(op), undo(), clearOps(), opsCount(),
size() → {w,h}, pixelAt(x,y) → [r,g,b,a], countRed(x,y,w,h) → n,
hitTest(x,y) → index|null, selectAt(x,y) → index|null, selectedIndex() → index|null,
moveSelected(dx,dy) → bool, deleteSelected() → bool,
handleAt(x,y) → 'nw'|'n'|…|'p1'|'p2'|null, resizeSelected(handle,dx,dy) → bool,
countColor(x,y,w,h,[rLo,rHi,gLo,gHi,bLo,bHi]) → n, opAt(i) → op の複製|null }`
（countRed は領域内の「赤系（r≥180, g≤90, b≤90）」画素数 — 枠・矢印・テキストの描画検証用。
selectAt は UI のクリック選択と同一コードパス）

## 検証手順

> **合否の正本は `./test/run mask` が全 pass（コンソールエラー0件を含む）。**

実機スモーク: 実スクショを Ctrl+V → モザイク → PNG コピー → Teams/Excel に貼れること
（画像の clipboard.write は file:// で理論上可だが実機未検証 — 調査時の注記）。
**日本語 IME でのテキスト入力**（変換中 Esc が編集を壊さないこと）は合成イベントで再現できないため実機で（v3）。

## やらないこと

- ガウスぼかし（復元リスク。上記）／ 自動 PII 検出（OCR が必要 — LLM/別ツールの領分）
- 画像・履歴の保存（機密を localStorage に残さない）
- Redo・レイヤー・自由曲線（要望が出たら）
- **タッチ操作**（ハンドルは指では掴めない。マウス/トラックパッド前提 — v3 決定）
- **テキストのフォントサイズ変更・text のリサイズハンドル**（op 形と描画モデルの全面改変になる。
  移動＋再編集で足りるのを見てから）
- **複数選択（ラバーバンド）・図形のコピー/複製（Cmd+D）**（要望が出たら）

## 決定事項（2026-08-14）

- **MK-Q1**: カテゴリ → 「画像」を新設（既存4分類のどれでもない）
- **MK-Q2**: マスク方式 → ピクセル化＋黒塗りのみ（ぼかし非搭載は設計判断であり手抜きではない）
- **MK-Q3**: 既定ツール → mosaic（開いて貼って即マスクが最頻動線。選択ツールを足しても不変）
- **MK-Q4**（v2）: 選択は**専用ツール** — 描画ツールのままクリックに選択の意味を持たせると、
  「図形の上に新しい図形を置く」動線と衝突する
- **MK-Q5**（v2）: 選択枠は**オーバーレイ（別キャンバス）** — メインキャンバスに描くと
  選択中のコピーで破線が PNG に混入する
- **MK-Q6**（v2）: Undo は**スナップショット履歴**に一般化 — 「ops を1つ pop」のままだと
  移動の取り消しが「図形ごと消える」という驚きになる
- **MK-Q7**（v3）: テキストは**その場編集** — 「先に打ってから配置」は一般的な UI に存在しない（利用者指摘）。
  確定/取消の意味論は Excalidraw 準拠（2026-08-15 に textWysiwyg.tsx で一次確認）
- **MK-Q8**（v3）: 描画後は**自動選択＋選択ツールへ復帰**（PPT 標準）。「連続描画」チェックで
  連続モザイク動線（MK-Q3）を保護。プログラム的復帰は選択を解除しない（利用者切替のみ解除）
- **MK-Q9**（v3）: 編集セッションは**状態機械** — グローバル操作（コピー・保存・Undo・クリア・
  ツール切替）の前に強制確定、画像取り込みだけは破棄（敵対的レビュー 2026-08-14 指摘9:
  「編集中テキストが写っていない PNG の無言コピー」を封じる）
- **MK-Q10**（v3）: リサイズは**クランプ方式**（反転なし）・text にハンドルなし
- **MK-Q11**（v3）: ナッジの1手まとめは**タイマー不使用**（時間窓はテストを flaky にする）
- **MK-Q12**（v3）: ドラッグ移動に**画面 3px の閾値**（ダブルクリック時の幻の微小移動を Undo 履歴に残さない）
- **MK-Q13**（v4）: 黒塗りは**黒固定** — マスキングに色選択を持ち込まない（白塗りの要望が出たら別途）
- **MK-Q14**（v4）: パレットは**5色固定** — 自由色ピッカーは選択肢過多とプラットフォーム差を招く
- **MK-Q15**（v5）: 白塗りは**独立ツール**（fill の白）。パレットはマスク系に効かせない（MK-Q13 維持）
- **MK-Q16**（v5）: バッジの採番は**最大値+1・振り直さない**（置いた順の意味を保つ）
- **MK-Q17**（v5）: 切り抜きは**確定式・Undo 対象外** — 画像履歴は機密画像の複製保持になり
  「保存しない」方針と矛盾する。確定前プレビューが誤爆防止を担う
- **MK-Q18**（v5）: Shift 制約は描画（正方形・45°）と移動（軸ロック）のみ。リサイズ等比は見送り
- **MK-Q19**（v5）: 複製は +10,+10・複製側を選択。バッジは次番号を振る
