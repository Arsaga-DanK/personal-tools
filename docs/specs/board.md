# board 仕様書兼テストケース

## 概要

付箋ボード。`web/board.html`、表示名 `Sort Ideas`、カテゴリ: 発想。
ブレインストーミング用: ダブルクリックで付箋を置いて直接入力 → ドラッグで並べ・色で分け・
線で結び → **md アウトラインで書き出し**（Obsidian ノートへ）と **PNG コピー**。
テキスト駆動の Draw Mindmap と役割分担（Draw = 木構造を書く / Sort = 出した発想を並べる）。

設計の土台は 2026-08-17 の敵対的レビュー（15指摘）。操作エンジンは web/mask.html v2〜v6 と
同型（**コピーして専用化** — Mask は添字選択・board は id 参照で構造が違うため lib 抽出は見送り。
vaultlint の lib/vault.js 見送りと同じ構図）。

## データモデル（フラット必須 — スナップショット Undo は浅コピー）

```
note      = { id, x, y, text, color }     // 幅は固定 NOTE_W=168・高さはテキストから毎描画で導出
connector = { id, a, b }                  // a/b = note の id（無向・中心間の直線）
```

- **全オブジェクトに安定 id**（採番 = 既存最大値+1・振り直さない — MK-Q16 と同型。
  添字参照は削除でずれる — レビュー F4）
- ネストしたフィールドを持たない（浅コピー履歴のエイリアス事故 — F13）。
  折返し結果は保存せず描画時に計算（id+text のキャッシュは履歴の外）

## キャンバス（Mask からの意図的乖離 — F2）

- **論理 1600×1000 固定・CSS 1:1 表示・白背景**。`max-width:100%` は使わない
  （縮小すると文字が読めない — board は文字を読む道具）。狭い画面では
  **ラッパ要素の中でスクロール**（ページ自体は横スクロールさせない — 幅390 規約と両立）
- **devicePixelRatio 対応**（バッキングストア dpr 倍 + ctx.scale — 文字のぼやけ防止）
- 付箋の作成・移動はキャンバス内にクランプ（外に出た付箋は触れない幽霊になる — F12）

## 付箋

- **作成**: 空白をダブルクリック → その場に編集ボックス／［付箋を追加］ボタン → 中央から
  +16,+16 のカスケード配置で編集開始。**編集の確定に使われたクリックから合成された
  ダブルクリックでは新規作成しない**（確定のつもりが新規付箋になる事故 — F7）
- **編集**: 付箋をダブルクリック → 編集ボックス（Mask v3 と同じ状態機械: blur/Esc/外側クリックで
  確定・IME ガード・空で確定 = 新規は作らない/既存は削除・1手 Undo）。
  確定時に canvas の折返しで再計算するため**改行位置が編集中と僅かに動くのは許容**（spec 明記）
- **固定幅 168px・自動高さ**（テキスト量で伸びる）。リサイズハンドルなし（F10 — FigJam/Miro も
  付箋は固定幅。折返しリフローと Mask 最大級のサブシステムを丸ごと省ける）
- **折返しは文字単位**（日本語は空白区切り不可 — `Array.from` でコードポイント分割し
  measureText の貪欲詰め。サロゲートペア安全）
- **色は淡色5枚**（黄 `#fef08a`・桃 `#fbcfe8`・青 `#bfdbfe`・緑 `#bbf7d0`・灰 `#e5e7eb`）＋
  文字は濃色固定 `#1f2937`（Mask の高彩度5色を塗りに使うと文字が読めない — F11）。
  スウォッチは新規付箋の既定色 ＋ 選択中の付箋に適用（Mask の書式規則と同型）

## 操作（Mask v2〜v6 と同型）

- ドラッグ移動（画面3px 閾値・Shift 軸ロック・origs 方式）・ラバーバンド（完全内包）・
  Shift+クリックのトグル・Cmd+A・Delete/Backspace・Cmd+D 複製（+16,+16。**線は引き継がない**）・
  矢印キー（1px・Shift 10px・連続1手）・**スナップショット Undo**（notes+connectors を1履歴に）
- 入力要素フォーカス中・IME 中はキーボード操作を奪わない（isTextEntryTarget と同型）

## 結線（v1 に含む — 利用者「必要になりそうな機能は最初から考慮」2026-08-17）

- ［結線］モード: 付箋Aをクリック（片端確定・A に強調枠）→ 付箋Bをクリックで線が引ける。
  無向・**中心間の直線**・付箋の下層に描画
- **自己ループ（A→A）と同一ペアの重複線は無視**（黙って引かない）
- **付箋の削除は接続線を道連れ**（1手の Undo でまとめて戻る — F4）。複製は線を引き継がない
- 選択ツールで**線もクリック選択できる**（線分から 8px — Mask の distToSegment）。
  Delete で削除・線は移動しない（端点は id 参照なので付箋の移動に自動追従）
- **pending（片端確定）× グローバル操作のマトリクス**（F5）: Esc・空白クリック・
  モード切替でキャンセル／コピー・md 書き出し・Undo・クリアは**先頭で自動キャンセル**（保存は pending を持たない）

## 出力

- **PNG コピー**: コンテンツの外接矩形＋余白24px でトリムした白背景 2 倍 PNG（F6。
  付箋ゼロならバナー案内でコピーしない）。Safari の Promise<Blob> パターン（Mask と同型）
- **md 書き出し**（クリップボード — ToolUI.copy）: **決定的で説明可能な規則のみ**（F3）
  - 既定 = **読み順**: y の重なりで行バンドを作り、行内は左→右・行間は上→下
  - ［色ごとに見出し］オン = 色をパレット順に `## 黄` などの見出しで区切り、色内は読み順
  - 付箋の複数行: 1行目が `- ` の箇条書き・2行目以降はインデントした継続行
    （`- ` 始まりの付箋テキストでも md が壊れない）
  - 結線があれば末尾に `## つながり` として `- A ⇔ B`（作成順・A/B は各付箋の1行目）

## 保存（localStorage — Mask と違い保存する。F8）

- `tools:board` に `{notes, connectors}` を自動保存（デバウンス 300ms＋pagehide/visibilitychange
  フラッシュ）。**undo 履歴は保存しない**（quota 死）
- 復元はキーごとに型・値域ガード。壊れた付箋は**件数を warn** して落とす（黙って捨てない）
- ボードは1枚（複数ボードは v2）。持ち出しは md 書き出しが担う

## 純関数・フック（UI と同一コードパス）

`window.board = { addNote(x,y,text,color) → id, notes() → note[], connectors() → conn[],
connect(idA,idB) → bool, selectAt(x,y), selectedIds() → ['n1','c2',…]（種別接頭辞つき・昇順）,
moveSelected(dx,dy), deleteSelected(), undo(), clearAll(), buildMd({byColor}) → string,
hitTest(x,y) → {type:'note'|'conn', id}|null }`

## 検証手順

> **合否の正本は `./test/run board` が全 pass（コンソールエラー0件を含む）。**

実機スモーク: PNG コピー → Teams/PowerPoint、md 書き出し → Obsidian ノートに貼れること。
日本語 IME での付箋入力（変換中 Esc が編集を壊さない）。

## やらないこと（トリガー付き）

- **付箋のリサイズ**（F10 — 固定幅×自動高さで足りるのを見てから）
- **ズーム・パン・無限キャンバス**（F2 — 1600×1000 で足りなくなったら）
- **複数ボード**（F8 — 持ち出しは md 書き出し。2枚目が本当に要る実測が出たら）
- **vault 連携・FSA**（F9 — 第二の正本問題。md 書き出しのコピペ運用で足りるのを見てから）
- **結線由来の md 入れ子・近接クラスタの階層化**（F3 — 非決定的。読み順と色ごとで足りるのを見てから）
- 自動整列・タッチ操作・自由色

## 決定事項（2026-08-17）

- **BD-Q1**: 表示名 `Sort Ideas`（動詞 Sort = 発想を並べ・まとめる行為。Draw Mindmap と
  「テキスト駆動 = Draw / 直接操作 = Sort」の対比。Stick Notes は Sticky のタイポに見え
  名詞が対象でないため不採用）
- **BD-Q2**: 描画は **canvas 一枚**（PNG コピーが一級出力・DOM→PNG の困難は mermaid の
  htmlLabels 無効化で一次実証済み・Mask エンジンが canvas 前提）。編集中 textarea と
  確定後 canvas の折返し微差は許容（Excalidraw と同構造）
- **BD-Q3**: エンジンは**コピーして専用化**（id 参照 vs 添字・保存有無・リサイズ有無で構造が違う。
  lib 抽出は「同じ修正を両方に入れた実測」が出たら再判断）
- **BD-Q4**: 結線は v1 に含む（利用者指示）。ただし安定 id・削除道連れ・複製非継承・
  pending マトリクスを先に固めた（F4/F5）
- **BD-Q5**: md の順序は**読み順＋色ごと**のみ（近接クラスタは閾値依存で説明不能 — F3）
- **BD-Q6**: 履歴は保存しない・単一ボード（F8）
