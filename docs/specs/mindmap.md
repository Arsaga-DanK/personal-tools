# mindmap 仕様書兼テストケース

## 概要

アウトラインからマインドマップを描くツール。`web/mindmap.html`、表示名 `Draw Mindmap`、
カテゴリ: **発想（新設）**。左にインデント付きの箇条書きを打つと右にマインドマップが
リアルタイム描画される。**思考の速度で打てる**（ドラッグ配置をしない）のが狙いで、
テキストがそのまま vault のノートに貼れる（正本問題が生じない）。
描画は同梱 mermaid の mindmap（`lib/mmd.js` — diagram/gantt と共有）。
直接操作の付箋ボード（board）は別ツール（要件定義から — tool-backlog）。

## 入力（Markdown のアウトライン — 2026-08-18 に md 記法へ寄せた MM-Q6）

**Obsidian のノートをそのまま貼れば図になる**のが基準。書き方は Markdown そのもの:

```md
# 新サービス案          ← 見出し = 階層（H1 が中心テーマ）
## 課題                 ← H2 = 1階層目
- 価格が高い            ← 見出しの下の箇条書き = その1つ下
  - 特に初期費用        ← 字下げでさらに下
## 打ち手
1. 無料プラン           ← 番号つきリストも同じ
```

- **見出し（`#`〜`######`）= 階層**。`#` の数 − 1 が深さ（H1=中心テーマ・H2=1階層目…）。
  **最初の見出しより上の階層は作れない**（H3 から始めてもそれが中心テーマになる）
- **箇条書き（`- ` `* ` `+ ` `1. `）**は**直前の見出しの1つ下**から始まり、字下げで深くなる
- **見出しが1つも無ければ、最初の内容行が中心テーマ**（従来どおり。素の箇条書きだけでも書ける）
- インデントは**タブ1個 = 1階層**。スペースは**最小の字下げ幅を1階層**として自動換算
  （2スペースでも4スペースでも合う — MM-Q4）
- **コメントは `%%`**（Obsidian の記法。`%%` 始まりの行は図に出ない）。空行は無視
- **貼り付けたノートに混ざる記法は落とす**（Obsidian からそのまま持ってくるため — MM-Q7）:
  | 入力 | 図に出るもの |
  |---|---|
  | `- [ ] タスク` / `- [x] 済み` | `タスク` / `済み`（チェックボックスは外す） |
  | `[[ノート]]` / `[[ノート\|別名]]` | `ノート` / `別名` |
  | `[表示](https://…)` | `表示` |
  | `**強調**` / `*強調*` / `` `code` `` | `強調` / `強調` / `code` |
  | 先頭の YAML front matter（`---` で囲まれた塊） | 出さない |
- ノード文字列の `( ) [ ] { }` は全角 `（）［］｛｝` に置き換える
  （mermaid mindmap の形状指定記法と衝突するため — 黙って変換・spec に明記）
- **2つ目以降のルート（レベル0）行は警告して1階層下げる**（mermaid mindmap はルート1つ。
  図を壊さない最善 — MM-Q2）

## 変換（純関数 `buildMindmapDsl(text)` → `{dsl, warnings}`）

```
mindmap
  root((中心テーマ))
    課題
      価格が高い
```

- 内容行が無ければ `{dsl: null, warnings}`（描画しない）

## UI

- 2ペイン: 入力（アウトライン）／出力（マインドマップ）。デバウンス 300ms・
  エラー時は前回の図を保持（diagram と同じ標準形）
- ［PNG をコピー］（primary・Cmd/Ctrl+Enter・白背景2倍）・サンプル投入（空のときだけ）
- 入力を自動保存（`tools:mindmap`・100KB cap・pagehide フラッシュ）

## 純関数・フック（UI と同一コードパス）

`window.mindmap = { buildMindmapDsl(text) → {dsl, warnings},
render(text) → Promise<{ok, error|null}>, svgInfo() → {present, nodes} }`

## 検証手順

> **合否の正本は `./test/run mindmap` が全 pass（コンソールエラー0件を含む）。**

実機スモーク: PNG コピー → Teams/PowerPoint に貼れること。

## やらないこと

- ノードの直接操作（ドラッグ・色分け・自由配置）— **付箋ボード（board）の領分**（別ツール）
- アウトラインの保存正本化（テキストは vault のノートへコピペ運用 — Fill と同じ整理）
- mermaid mindmap の形状・アイコン記法の露出（箇条書きだけで完結させる）

## 決定事項（2026-08-15）

- **MM-Q1**: カテゴリ「発想」を新設（ブレスト系は既存6分類のどれでもない。board もここに入る）
- **MM-Q2**: 複数ルートは**警告して1階層下げる**（エラーで止めない — ブレスト中の手を止めない）
- **MM-Q3**: `()[]{}`は全角へ黙って変換（mermaid の記法衝突。警告の洪水はブレストの邪魔）
- **MM-Q4**（2026-08-17）: md リスト対応 — 記号行は階層+1・スペース字下げは最小幅を自動検出
  （利用者「md 形式で書いたら良いんじゃない？」。Obsidian からの貼り付け互換）
- **MM-Q5**（2026-08-17）: Tab はインデント（lib/edit.js。Esc→Tab が脱出経路 — 利用者
  「ブラウザだと Tab が打ちにくい、次のボタンに飛ぶ」）
- **MM-Q6**（2026-08-18）: **`#` はコメントではなく見出し（階層）**にする。
  利用者「作り方をタブじゃなくて md 形式っぽくできませんか」。
  MM-Q4 で箇条書きは通るようにしたが、**`#` をメモ行にしていたため Obsidian のノートを貼ると
  見出しが全部消えて構造が失われていた**（md として最も自然な階層表現を捨てていた）。
  コメントは Obsidian の `%%` に移す（md 互換を保ったまま逃げ道を残す）。
  **破壊的変更**: 従来 `#` をメモに使っていた入力は、その行が図に出るようになる
  （入力は作業中のテキストで正本ではないため許容する — spec「やらないこと」の保存正本化なし）
- **MM-Q7**（2026-08-18）: 貼り付け由来の md 記法（チェックボックス・`[[ ]]`・`[](url)`・
  強調・インラインコード・front matter）は**黙って落とす**。警告は出さない
  （ブレスト中に警告の洪水を出さない — MM-Q3 と同じ方針）。
  `[[ ]]` を残すと `()[]{}`の全角化で `［［…］］` になり読めなくなる問題も同時に解消する
