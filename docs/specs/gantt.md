# gantt 仕様書兼テストケース

## 概要

タスクと期間の表からガントチャート画像を作るツール。`web/gantt.html`、表示名 `Draw Gantt`、カテゴリ: PM。
1行1タスクの簡易表を書くと横棒チャートが描かれ、**PNG コピー**で資料・Teams に貼る。
**管理はしない**（進捗・依存・保存データの正本を持たない — tool-backlog の採択条件）。
描画は同梱 mermaid（`lib/mmd.js` — diagram と共有。テーマ・PNG 化の規約はそちらが正本）。

## 入力（1行1タスク。区切りはタブ または カンマ）

```
セクション名          ← 区切りのない行はセクション見出し
タスク名<TAB>開始<TAB>終了または日数
```

- 開始: `YYYY-MM-DD` / `YYYY/M/D`（正規化して YYYY-MM-DD）
- 終了: 日付（同上）または日数（`5d` / `5日`）
- **終了日はその日を含む**（mermaid の終了日は排他 — 2026-08-17 に実測。DSL 生成で +1 日して吸収する。
  「金曜まで」と書けば金曜まで塗られる）
- **終了 < 開始 は警告して1日バーに丸める**（mermaid は黙って変な図を描く — 実測。
  taskboard の invalid 扱いと同じ規則）
- `#` 始まりはコメント。空行は無視
- タスク名の `:` は `：`（全角）に置き換える（mermaid gantt の区切り文字と衝突するため）
- 解釈できない行は**その行番号つきで warn**（他の行は描く — 落ちない）

## 変換（純関数 `buildDsl(text, {excludeWeekends})` → `{dsl, warnings}`）

生成する mermaid gantt DSL:

```
gantt
dateFormat YYYY-MM-DD
axisFormat %m/%d
excludes weekends        ← オプション（既定オン — PM 用途は営業日感覚が普通）
section セクション名
タスク名 :t1, 2026-08-18, 2026-08-22
```

- タスク ID は出現順に t1, t2, …（利用者には見せない）
- タスクが1つも無ければ `{dsl: null, warnings}`（描画しない）

## 取り込み（貼るだけ — 体験の標準①⑤。2026-08-17 敵対的レビュー反映）

貼り付け時に形式を自動判別して表テキストへ変換する（純関数 `importText(raw)` →
`{text, warnings, kind: 'tasks'|'plan'|'excel'|null}`。UI の paste と同一コードパス）:

- **tasks.md（Obsidian Tasks 記法）の直貼り**: `- [ ] 本文 🛫 A 📅 B` と `## 見出し` を認識
  | tasks.md 側 | 変換 |
  |---|---|
  | `## 見出し` | セクション行 |
  | 未完了 ＋ `🛫`＋`📅` | `名前<TAB>🛫<TAB>📅`（終了日は含む — GN-Q4 でそのまま） |
  | `🛫` のみ / `📅` のみ | その日の**1日バー**（📅 のみを捨てると期限運用のタスクが全滅する） |
  | 日付なし / 完了 `[x]` / 中止 `[-]` | スキップして**件数集約**の警告（行番号の洪水にしない） |
  | 保留 `[h]`・着手中 `[/]` | 未完了として取り込む |
  | 子タスク（タブ字下げ） | 全角スペース字下げを名前に前置（フラット化） |
  | メタトークン（🆔・⛔・優先度・⏳・✅・❌）・`[[ ]]` | 名前から除去（`[[x]]` は中身を残す・タグは残す） |
- **taskboard「計画をコピー」出力**（ヘッダー `内容 開始日 期限 日数 状態 セクション`）:
  ヘッダーで判別。セクション列の変化からセクション行を生成・済/中止はスキップ（件数）・期限空欄は1日バー
- **「Excel用コピー」形式**（`状態 内容 …` ヘッダー）は**変換せず案内**
  （「タイムライン表示の『計画をコピー』を貼ってください」— 列順が違い全滅するため）
- 変換して貼った先頭に **`# 取り込み: <今日>` コメント**を挿す（鮮度の見える化 —
  古いスナップショットを正として配らない。コメント行なので図には出ない）

## チェーン入力（開始を省略 = 前のタスクの続き）

- `名前<TAB><TAB>3d` のように**開始を空欄にすると、前のタスクの終了の翌営業日**から始まる
  （土日除外オフなら翌暦日）。WBS の大半は連続タスク — タスク名と日数だけで表が組める
- 前行が日数指定の場合の終了は**営業日ウォーク**（開始日を1日目として営業日を数える）で算出。
  mermaid の週末延長規則と一致することを実測2ケース（金曜3d→火曜・土曜2d→火曜）で確認済み
- 先頭行の開始空欄は警告してスキップ

## 行エディタ（記法を知らなくても表が組める — 体験の標準①②③。2026-08-17）

入力ペインの表示を「テキスト / 行エディタ」のセグメント2ボタンで切り替える
（`.tabs` は流用しない — ui.css の再定義禁止。選択は保存・復元、既定はテキスト GN-Q10）。
**テキストが正本・行エディタはその窓**（GN-Q9）。行エディタ表示中は textarea を hidden にし、
各行をフォーム行として表示する。編集は**編集した行だけを最小スプライスで書き戻す**
（他の行はバイト不変）。

### 行の分類（純関数 `parseRows(text)` → 行配列。buildDsl と同じトークン化規則）

| 型 | 判定 | 表示 |
|---|---|---|
| （空行） | 空か空白のみ・タブなし | **行として出さない**（テキストには保持。行番号ガターの欠番で分かる） |
| comment | `#` 始まり | 読み取り専用（muted・生テキスト） |
| section | 区切り（タブ・カンマ）なし | 幅広テキスト入力1つ |
| task | 3列以上・2列目が normDate 可か空・3列目が normDate/normDuration 可か空 | 名前・開始(date)・終了(date)・日数の4入力＋行操作 |
| invalid | 上記以外（列不足・解釈不能トークン） | **生の1行をテキスト入力で編集できる**（直った瞬間に task/section へ昇格 — GN-Q12） |

- `<TAB><TAB>` だけの行（全トークン空）は task（追加直後の空行。buildDsl は従来どおり黙ってスキップ）
- 各行は**元トークンを保持**し、シリアライズは編集したフィールドのトークンだけ差し替える
  （`2026/9/1` 形式の行の名前だけ編集しても日付トークンはバイト不変）。4列目以降のトークンも保持。
  名前トークンは trim しない（取り込みの全角スペース字下げを保つ）。
  カンマ区切りの行を編集したときだけ、その行の区切りがタブに統一される

### 書き戻し（コミット）の規則（GN-Q11 — date input の実測に基づく）

- テキスト系（名前・セクション・日数・invalid 生行）: input の 400ms デバウンスでコミット。
  blur・Enter・ビュー切替・コピー・pagehide で即フラッシュ
- **date input は「有効値（normDate 可）は change の 400ms デバウンス・空値は blur 時のみ」**
  — 実測: date input は毎キー input+change を発火し、年の打ち直し1打目で `0001-08-18`、
  Backspace 1回で空文字が飛ぶ。空を即コミットすると打ち直し途中が黙ってチェーン行に化ける
- 日数は `5`/`5d`/`5日` を `Nd` に正規化。解釈できない値はコミットしない（フィールドに invalid 表示）
- 終了と日数は相互排他 — **相手が有効値を確定した時点で**クリア（1スプライス＝1 Undo 単位）
- サニタイズ: 全フィールドでタブ・改行は空白へ。名前・セクションの行頭 `#` は全角＃へ・
  セクションのカンマは全角カンマへ（行の型シフト防止 — 名前の `:` 全角化と同じ流儀）

### 行の操作

- ［＋ タスク］［＋ セクション］: 末尾に追加（末尾改行の有無を見て結合 — 空行を増殖させない）
- 任意の行のフィールドで **Enter = その行の下に新規タスク行を挿入**（Excel の筋肉記憶。IME 中は無効。
  挿入前に編集中フィールドをフラッシュ — date input の Enter は change を伴わない実測に対処）
- 上へ / 下へ: 隣の**表示**行と行テキストを交換（バイト交換）。削除: その行だけ削除
- フォーカス規則: 追加/Enter=新行の名前・削除=次行（なければ前行）の先頭フィールド・
  取り込み=挿入した先頭行・ビュー切替=先頭フィールド。**フィールド編集では DOM を再構築しない**
  （フォーカス維持 — coding-rules「再描画でボタンを作り直さない」）
- **Undo（Cmd/Ctrl+Z・エディタ表示中のみ）**: テキストスナップショット履歴で1手戻す
  （cap 50・redo なし GN-Q13）。プログラム代入は textarea のネイティブ undo を殺すため（実測）自前で持つ
- チェーン行（開始空欄）は**実効開始日をキャプション表示**（buildDsl が返す `chained` から。
  土日除外の切替でも更新）。date input は placeholder が効かないため、空欄の意味を可視化する
- 行番号ガターを表示（警告の「N行目」と対応 — 空行を隠しても指し先が分かる）

### 同期の防壁（GN-Q9）

- textarea.value を書き換える経路は5つ: エディタのスプライス・サンプル投入・restore・
  paste 取り込み・テスト注入。**スプライス以外の経路の後は必ずエディタを再構築する**
- スプライス前に「構築時に覚えた行の生テキスト」と「現在の該当行」を比較し、
  **不一致なら書き込まずに再構築**（鮮度ガード — 外部書き換え後の誤スプライスを構造的に防ぐ）
- 500行を超えるテキストでは行エディタを開かない（バナーで案内しテキストに留まる — 性能ガード。
  上限の定数と文言の数字は二重管理）
- エディタ表示中の paste はルートで捕捉して importText で判別（tasks/plan=変換して末尾挿入＋再構築・
  excel=案内バナー・不明=既定動作でフォーカス中の入力へ）

## UI

- 2ペイン: 入力（表テキスト or 行エディタ）／出力（チャート）。デバウンス 300ms・
  エラー時は前回の図を保持（diagram と同じ標準形）
- オプション: ［土日を除外］チェック（既定オン）
- ［PNG をコピー］（primary・Cmd/Ctrl+Enter・白背景2倍 — lib/mmd.js）・サンプル投入
  （行エディタ表示中も見える。押したらエディタを再構築）
- 入力・オプション・ビュー選択を自動保存（`tools:gantt`・100KB cap・pagehide フラッシュ。
  ビューは enum ガードで復元・無指定はテキスト）

## 純関数・フック（UI と同一コードパス）

`window.gantt = { buildDsl(text, opts) → {dsl, warnings, chained}, parseRows(text) → 行配列,
importText(raw) → {text, warnings, kind}, render(text) → Promise<{ok, error|null}>,
svgInfo() → {present, nodes} }`

- `chained` は開始空欄で補完した行の「テキスト行番号（0始まり）→ 実効開始日」の対応
  （行エディタのキャプションの正本）

## 検証手順

> **合否の正本は `./test/run gantt` が全 pass（コンソールエラー0件を含む）。**

実機スモーク: PNG コピー → PowerPoint/Teams に貼れること。
行エディタの date input は**実 Chrome のセグメント編集**（年の打ち直し・Backspace）で
「途中値が正本に書き込まれない（GN-Q11）」を確認する — headless は非セグメントで再現できない
（verification-notes §4）。

## やらないこと

- 進捗率・依存関係・マイルストーン・担当者（**管理はしない** — 原則2。書きたくなったら
  Excel か本物の PM ツールの領分）
- 祝日の除外（dates の祝日テーブルとの共有は「2番目の利用者」だが、mermaid の
  `excludes` は日付列挙が必要で表が肥大する。土日除外で足りるのを見てから）
- 保存データの正本化（入力は作業状態の自動保存のみ — テンプレは vault のノートへ）
- 行エディタのドラッグ並べ替え（GN-Q14 — 上へ/下へと Enter 挿入で足りるのを見てから。
  トリガー: 10行超の表で並べ替えが苦痛という実測）
- 行エディタの redo（Cmd+Shift+Z — GN-Q13。mask/board も undo のみで要望ゼロ）

## 決定事項（2026-08-15）

- **GN-Q1**: 描画は mermaid gantt に委譲（自前 canvas 描画はしない — 同梱済みエンジンの2番目の利用者）
- **GN-Q2**: 土日除外は**既定オン**（PM 用途は営業日感覚が普通。チェックで切れる）
- **GN-Q3**: 祝日除外は見送り（上記）。トリガー: 利用者が祝日ずれを指摘したら dates のテーブルを共有
- **GN-Q4**（2026-08-17）: 終了日は**含む**に統一 — mermaid の排他仕様は DSL 生成の +1 日で吸収
  （敵対的レビューの実測: `2026-08-17, 2026-08-21` は4日分しか塗られない）
- **GN-Q5**（2026-08-17）: 日数と終了日の**相互変換はしない** — 土日除外下では全単射にならない
  （土曜開始の `2d` が3日幅になる等、mermaid の延長規則が直感と合わない — 実測）
