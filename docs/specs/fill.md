# fill 仕様書兼テストケース

## 概要

定型文テンプレの差し込みツール。`web/fill.html`、表示名 `Fill`、カテゴリ: 変換・比較。
テンプレ本文に `{{変数}}` を書くと入力フォームが自動生成され、埋めると完成文が
リアルタイムに出来上がる。日報・週報・議事録送付・依頼文など「毎回少しだけ変わる
定型連絡」を、テンプレの上書き事故なしで量産する。

2026-08-14 の外部調査で「単機能・ブラウザ完結のテンプレ差し込み」が空白地帯であることを
確認して採択（既存解は Chrome 拡張・Outlook テンプレなど環境依存ばかり）。

## 変数の構文

- `{{名前}}` — `{{` と `}}` で囲む。中身の前後空白は無視（`{{ 名前 }}` = `{{名前}}`）
- 変数名に `{` `}` と改行は使えない（`{{a` のような閉じ忘れは変数にならず本文のまま）
- **同名の変数は1つの入力欄**になり、全出現箇所へ同じ値が入る
- フォームの並び順はテンプレ内の初出順
- **組み込み変数 `{{今日}}`**: 入力欄に今日の日付（`YYYY-MM-DD`）が自動で入る。
  編集可（形式を変えたい・別の日にしたいとき）。自動なのは初期値だけ — 隠れた置換はしない

## 出力

- 未入力の変数は出力に `{{名前}}` のまま残し、サマリに「未入力: N件（名前…）」を warn 表示
  （空文字で埋めると気付かず送ってしまう）。全部埋まれば件数表示は消える
- ［結果をコピー］（`ToolUI.copy`、primary ボタン）

## 保存（terms と同じ「作業状態の自動保存」のみ）

- localStorage（`tools:fill`）に**テンプレ本文と変数の値**を自動保存（300ms デバウンス）
- **名前付きテンプレの管理はやらない** — 練り上げたテンプレ集の正本は vault のノートに置き、
  使うときに貼る運用（CLAUDE.md「永続データの正本は vault」。ツール内に第二の正本を作らない）

## 純関数・フック（UI と同一コードパス）

`window.fill = { parseVars(text) → [名前の配列（初出順・重複なし）],
render(text, values) → { output, missing: [未入力の名前] } }`

## テストケース

| ID | 操作 | 期待 |
|---|---|---|
| FL-01 | `parseVars('{{a}}と{{b}}と{{a}}')` / `parseVars('{{ 名前 }}')` | `['a','b']`（初出順・重複なし）/ `['名前']`（前後空白は無視） |
| FL-02 | `render('x{{a}}y{{a}}', {a:'Z'})` | `{output:'xZyZ', missing:[]}`（全出現箇所に入る） |
| FL-03 | `render('x{{a}}y', {})` / 値が空文字 | `{output:'x{{a}}y', missing:['a']}`（未入力はそのまま残す） |
| FL-04 | `parseVars('{{a')` / `parseVars('変数なし')` | `[]`（閉じ忘れ・変数なしは変数にならない） |
| FL-05 | テンプレに `{{今日}}` | フォームの「今日」欄に `YYYY-MM-DD` 形式の初期値が入る（編集可） |
| FL-U1 | テンプレ入力 → フォーム生成 → 値入力 | 変数ごとの入力欄（ラベル=変数名）が初出順に並び、出力がリアルタイム更新 |
| FL-U2 | 未入力あり | サマリに warn（「未入力」と件数）。全部埋めると消える |
| FL-U3 | ［結果をコピー］（writeText スタブ） | 完成文が渡り ✓ 表示・実クリップボードに書かない |
| FL-U4 | reload | テンプレ本文と変数の値が復元される（`tools:fill` envelope） |
| FL-U5 | 幅390px | ページの横スクロールなし |

ハブ導線: カテゴリ「変換・比較」に載り、title は `Fill`（表示名=英名なので表示名のみ）。

## 検証手順

> **合否の正本は `./test/run fill` が全 pass（コンソールエラー0件を含む）。**

## やらないこと

- 名前付きテンプレの保存・切替（正本は vault のノート。上記「保存」）
- 条件分岐・繰り返し・書式指定などのテンプレ言語（`{{変数}}` の置換のみ。
  凝った生成は AI の領分）
- `{{今日}}` 以外の組み込み変数（要望が出たら。自動置換は隠れた挙動になるため
  「初期値を入れる」方式を守る）

## 決定事項（2026-08-14）

- **FL-Q1**: テンプレ集の正本は vault のノート（コピペ運用）。ツールは作業状態の自動保存のみ
- **FL-Q2**: 変数の入力欄は1行の textarea（縦リサイズ可）— 議事録送付など複数行の値も入れられる
- **FL-Q3**: 未入力は空文字で埋めず `{{名前}}` のまま残して warn（気付かず送る事故の防止）
